# Medical Resume Agent

面向医学生的 JD 定制简历工具。它先把岗位要求与原始简历逐条匹配，再用可选的大模型进行受约束改写，并在导出前提示未确认数字、职责扩大和没有证据支持的要求。

## 特点

- 诊断和审校在本地完成，不依赖模型。
- 模型改写只可使用原始简历原文与用户确认的补充事实。
- 没有配置模型时，仍可生成保留原始证据的候选条目。
- 提供可编辑的医学求职简历模板、A4 投递预览与浏览器 PDF 打印。

## 本地运行

```powershell
python -m pip install -e .
Copy-Item .env.example .env
# 可选：在 .env 填入自己的 DeepSeek 配置
python -m medical_resume_agent
```

打开 `http://127.0.0.1:5000/`。

`.env` 仅保留在本机，不能提交到 GitHub。
