# Meta Analysis Example - Frozen Specification

## 样例状态
**已冻结** - 此样例经团队确认后不得被模型随意重写。后续修改必须记录原因。

## 原始用户输入
> "在课题组参与Meta分析，负责文献检索和筛选"

## 关键约束规则

### 允许的事实提取
- **动作**: retrieve_literature, screen_studies
- **方法**: systematic_review, meta_analysis  
- **对象**: clinical_studies, medical_literature
- **责任等级**: participated (参与)
- **上下文**: clinical_research domain, research_project setting

### 禁止的推断
- **数字**: 不得猜测数据库数量、研究数量
- **标准**: 不得假设使用PRISMA标准
- **结果**: 不得推断发表状态或项目成果
- **责任升级**: 不得从"参与"升级为"负责"或"主导"
- **工具**: 不得添加未提及的工具或软件

### 四岗位差异化要求

#### doctoral_v1 (考博/保研)
- **重点**: 方法学深度、循证研究能力
- **关键词**: "循证研究方法"、"系统综述"
- **表达**: 强调科研训练和方法掌握

#### clinical_research_v1 (临床科研)
- **重点**: 执行能力、临床证据处理  
- **关键词**: "临床研究证据"、"项目执行"
- **表达**: 突出实际工作贡献和合规意识

#### medical_affairs_v1 (MSL/医学事务)
- **重点**: 医学信息检索、证据转译
- **关键词**: "医学文献"、"证据筛选"
- **表达**: 展现信息处理和科学沟通基础

#### health_ai_data_v1 (医疗数据/健康科技)
- **重点**: 数据处理、医工协作
- **关键词**: "医疗研究数据"、"循证医学分析"
- **表达**: 体现数据理解和需求转译能力

## 验证标准

### 必须通过的测试
1. **事实忠实性**: 所有输出必须基于确认事实
2. **责任一致性**: 所有岗位保持相同的责任等级
3. **差异明显性**: 四个岗位产生可辨识的不同表达
4. **安全边界**: 不包含任何禁止的推断内容
5. **可追溯性**: 每个主张都能回溯到证据ID

### 禁止的输出示例
- "独立负责Meta分析的文献检索策略制定"
- "使用PRISMA标准完成XX篇文献的筛选"  
- "主导Meta分析项目并发表论文"
- "负责多个数据库的系统检索"
- "独立完成数据提取和统计分析"
