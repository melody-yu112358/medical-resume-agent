# 研究资料导航

此目录混合方法、来源观察、岗位验证与历史工具设计；文件存在不表示职业已发布。当前资产只见 [生成状态页](../CAREER_CATALOG_STATUS.md)，总阅读入口见 [文档导航](../README.md)。

| 类别 | 入口 | 如何使用 |
| --- | --- | --- |
| 扩展方法 | [广度扩展方法](career-catalog-breadth-plan-v1.md) | 维护来源类别、去重、分类和 coverage 定义 |
| 广度来源观察 | [采集记录入口](career-catalog-breadth/README.md) | 保留批次来源、范围建议和遗漏；不计为已发布职业 |
| 研究策略 | [中国覆盖矩阵](china-career-coverage-matrix-v1.md) | 有日期的研究层级建议，不是当前库存或市场统计 |
| 既有来源观察 | [相邻方向来源清单](adjacent-career-job-source-inventory-2026-08-17.md)、[医疗 AI 产品岗位研究](healthcare-ai-product-manager-jobs-2026-08-17.md) | 按采集日期理解；历史招聘不代表当前在招 |
| CRA 验证 | [scorecard](role-validation/cra/scorecard.md) | 读取当时的 corpus、评价范围与限制 |
| CDM 验证 | [scorecard](role-validation/cdm/scorecard.md) | 同上 |
| 器械应用支持验证 | [研究目录](role-validation/device-clinical-application/) | 同上 |
| 药物警戒验证 | [研究目录](role-validation/pharmacovigilance/) | 同上 |
| 法规医学写作验证 | [研究目录](role-validation/regulatory-medical-writing/) | 同上 |
| 历史研究工具设计 | [orchestrator](career-track-orchestrator-v1.md)、[dispatch connector](github-dispatch-connector-v1.md)、[event consumer](github-event-consumer-codex-task-connector-v1.md) | 工具和流程设计，不是职业分类或当前任务队列；操作规则仍以治理文件为准 |

研究材料中的 JD 来源、保留摘录、digest、排除项和人工评价不能用状态页替代；反过来，旧 Candidate 文件名也不决定后来是否已有 Canonical 源。来源只是背景研究时，不能称为 Career Card claim 的直接支持。
