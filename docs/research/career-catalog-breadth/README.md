# 广度来源观察 · 2026-09-06

这是公开定位整理后的首批采集事实，尚不是完整广度调查，也不是已发布职业目录。原始岗位名称、职责与资格摘要、来源状态、分类建议及摘要指纹集中保存在 [批次记录](batch-2026-09-06-v1.json)。本文只解释如何读取，不另维护候选清单。

本批探索了保险审核、医学内容、统计编程和医院非诊疗管理等范围，也保留了保险产品项目协调这一专业不限的跨行业样本。医学相关与跨行业分别记录；全部范围及与现有目录的关联均待人工审核。没有把候选自动登记为 Beta、Canonical、Career Card 或可解释目标。

## 读取与审查

- `source_snapshots` 保留短摘录及研究者转述，**不是完整网页快照**。SHA-256 仅校验 `retained_payload` 的规范 JSON 内容，不证明网页完整性、真实性或当前有效性；URL、来源段落/PDF页码便于复查。
- `candidates` 引用观察 ID；拟议名称、职能和现有目录关系均为建议。`human_review_pending` 不表示已经得到人工确认；生命周期尚未审查，不自动判定“不适用”。
- 资格摘要不是完整招聘条件，申请仍需回到原文核验。任务未展开就保留未知，医学教育管理不能省略资格要求，病案统计不能擅自归并为病案编码。
- 职责接近时记录相邻或未决关系，不凭标题相似自动归并。医学编辑与内容运营的边界仍待跨雇主核对；统计编程不直接等同 CDM。
- 来源只支持“观察到此岗位描述”，没有 Career Card 的人工逐 claim 支持关系，也没有个人适配结论。

新增采集批次使用新文件，保留旧记录与指纹。来源撤下或修订应另记访问观察，不覆盖本批所见内容；当前尚未建立自动来源监控。

## 尚未完成

本批是便利样本；跨行业、地区、层级和职能仍有明显遗漏，单角色多雇主核验不足，尚未形成冻结参考候选集或独立留出样本。不能计算全国职业覆盖率或内部参考集覆盖进度。未检索/不足的范围保存在批次记录中。
