# China Career Coverage Matrix v1

**Status:** current planning source for China-oriented medical-background
career coverage. This matrix recommends product coverage paths; it does not
create a Role Pack, routing target, or claim that any listed role is currently
available without the applicable runtime support.

## Method and limits

This is a dated research strategy reference (2026-09-06), not a live inventory.
Current assets and associations are generated only in
[Career catalog status](../CAREER_CATALOG_STATUS.md). Object types and naming
principles belong to [Career catalog structure](../CAREER_CATALOG_STRUCTURE.md).

Demand, medical fit and confidence are unmeasured planning judgments, not
national demand statistics, hiring probability or individual eligibility.
Recommended tiers describe a research approach, not current maturity or routing.
Academic / PhD is an application path and is excluded from employment-role coverage.
Boundary summaries require the applicable Pack and JD; they are not executable rules.

## Coverage interpretation

Directory breadth, source-backed knowledge, resume Pack support and explanation
support are independent dimensions. Collection methods, denominator/version
rules and the internal reference-set target are maintained only in the
[breadth expansion method](career-catalog-breadth-plan-v1.md). This matrix is
neither that reference denominator nor a measured coverage result.

## Selecting deeper research

Use source quality, observed task stability, user needs and boundary risk to
choose subsequent depth work. Review scientific communications separately from
regulatory writing; determine drug/device RA scopes from JD responsibilities;
distinguish biostatistics from statistical programming and tools such as SAS;
evaluate RWE and HEOR separately. These are scope distinctions, not a task order.
No recommendation here authorizes canonicalization or runtime routing.
