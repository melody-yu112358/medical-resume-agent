# China CRA Candidate scorecard

**Current tier:** Beta research. **Release Gate:** `FAIL — remain Candidate/Beta`.

The evidence file preserves three current public China-based CRO snapshots, a
fixed eight-persona set, mappings, negative mappings, and positive/partial/
negative evaluation cases. Stable scope is protocol/SOP/GCP-aligned study
execution support, documentation, data/query follow-up, and bounded site
coordination.

Hard gaps remain independent monitoring, site-lifecycle ownership, recruitment,
financial responsibility, and project leadership. Factuality, ownership, and
usefulness are not scored because no generated output has been audited; critical
unsupported claims are therefore not assessed, not zero. The track needs at
least the graduation-required JD coverage, reproducible evaluation outputs, and
conformance provenance before canonicalization review can be considered.
