可信生成链路

不是一段提示词，而是“事实确认—医学理解—岗位表达—主张审计—文件交付”的可追溯系统。

01 · INTAKE

原始输入

接住经历、现有简历和其他用户提供材料。

02 · FACT CARD

候选事实卡

原子化拆解、去重归并，并保留来源定位。

03 · FREEZE

用户确认 / 冻结

逐项核对，确认后形成可用事实基线。

04 · MEDICAL

医学能力解释

分开理解方法、数据工具、实验技术与检索资源。

05 · CLAIM GATE

表达与主张审计

Role Pack 只改变侧重；阻止责任升级与虚构结果。

06 · DELIVERY

可编辑交付

输出 Markdown、HTML 与可打印简历，并保留审校边界。

医学简历的产品边界

方向包会持续完善，因此这里不把当前分类固定成产品承诺；核心是不失真的医学能力翻译与可审计表达。

01 · CAPABILITY TAXONOMY

不堆关键词

Meta 分析属于研究方法；R / Python 是数据工具；qPCR / WB 是实验技术；PubMed / Embase 是检索资源。

02 · USER CONFIRMATION

确认权在用户

模型提出候选事实与表达，用户确认责任、范围和结果；不确定信息保留为待补充或保守表述。

03 · CLAIM GATE

规则阻止越界

检查事实一致性、能力映射与责任等级；禁止把参与写成主导，也不编造数字和成果。
