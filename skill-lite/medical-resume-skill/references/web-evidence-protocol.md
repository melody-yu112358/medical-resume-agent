# JD and public-evidence assistance

This is an optional mode for improving role-language alignment and checking public references. It never turns web content into evidence of the user's personal experience.

## Permission and inputs

Browse only when the user does one of the following:

- supplies a job description, URL, publication DOI, project page, or official institutional page; or
- explicitly asks to search for a target role, disease-area terminology, or public research reference.

State what will be searched and why. Do not search for the user's name, school, supervisor, social-media account, unpublished project, or any other personal information unless the user explicitly asks and the search is necessary for the task.

## Permitted uses

Use public material to:

- extract role responsibilities, recurring terminology, and stated requirements from a target JD;
- identify the language used in an official hospital, company, university, guideline, or journal source;
- verify a user-supplied DOI, publicly listed publication, or official project description;
- identify gaps between an advertised role and the user's confirmed fact card.

## Prohibited uses

Never use public material to:

- infer that the user performed an advertised responsibility;
- manufacture a patient count, study result, publication status, ownership claim, experimental technique, or timeline;
- copy a JD verbatim into the user's experience;
- state that a search result validates an unpublished or private claim.

## Required separation

Maintain three distinct records during the task:

```text
Confirmed personal facts      → eligible for resume claims
JD / public role terminology → eligible only for wording and gap analysis
Unconfirmed or inferred data → questions or [待补], never a resume claim
```

When presenting a rewrite, include a short note such as:

> Role alignment: this version foregrounds evidence synthesis and scientific communication because the supplied MSL JD values those capabilities. No JD requirement was added as a personal achievement.

## Search quality

Prefer the exact JD, employer career page, university or hospital page, guideline publisher, journal publisher, or DOI record. Summarize rather than copy. If sources conflict, say so and do not claim certainty.
